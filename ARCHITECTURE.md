# BrightPath System Architecture

## 1. Problem Statement
Educational institutions often struggle with fragmented platforms. Teachers use one system to share resources and another to grade assignments, while students face disjointed experiences trying to track their progress and deadlines.

## 2. Objectives
- Provide a unified, cloud-native Learning Management System (LMS).
- Ensure strict role-based access control (RBAC) separating student and teacher data.
- Offer an intuitive, premium, responsive user interface.
- Implement secure, authenticated file storage for assignments.

## 3. Technology Stack
- **Client**: React 19, Next.js 15 (App Router framework).
- **Styling**: Tailwind CSS v4, custom Shadcn-inspired design system.
- **Backend Infrastructure as Code**: AWS Amplify Gen 2 (TypeScript).
- **Database**: Amazon DynamoDB (managed by AWS AppSync).
- **Storage**: Amazon S3.
- **Authentication**: Amazon Cognito.

## 4. AWS Services & Responsibilities
- **Amplify Hosting**: Handles CI/CD from GitHub and serves the Next.js frontend globally.
- **Cognito**: Manages user identities, secure JWT issuing, and group-based roles (STUDENT, TEACHER).
- **AppSync / DynamoDB**: Provides a real-time GraphQL API interfacing with a NoSQL database. All backend authorization policies (e.g., students only seeing their own submissions) are enforced at the API resolver layer.
- **S3**: Stores course materials (`course-resources/`) and student uploads (`submissions/`), leveraging IAM policies generated by Amplify to restrict access securely.

## 5. Implementation Methodology
The project was built in phases following a modern decoupled architecture:
1. **Design System & UI Foundations**: Establishing the visual hierarchy.
2. **Cloud Schema Definition**: Modeling data relationships (`Course` -> `Assignments` -> `Submissions`) using Amplify Gen 2 TypeScript definitions.
3. **Integration**: Bridging the Next.js client with the Amplify client library.

## 6. Results and Limitations
- **Results**: A highly responsive, secure MVP that scales automatically using AWS Serverless infrastructure.
- **Limitations**: The current iteration does not implement real-time push notifications or robust rich-text editing for assignments. 

## 7. Future Enhancements
- Integration with AWS Step Functions for automated email reminders.
- Utilizing Amazon Bedrock to generate AI-assisted feedback for student submissions.
- Adding a calendar view for upcoming deadlines.
